## 1. 策略总览（三层 + 一次演练）

| 层 | 工具 | 测什么 | 跑法 | 时机 |
|---|---|---|---|---|
| L1 单元 | JUnit4 + runTest | 纯函数：DateParser / HtmlText / RssMapper /（M3）OPML | gradlew.bat test | M3-W4（可选前移 M1） |
| L2 仓储集成 | Robolectric + 内存 Room + Fake 网络层 | 去重幂等 / CASCADE / 错误隔离 / 304 跳过 | gradlew.bat test | M3-W4 |
| L3 手工验收 | AVD（Pixel 6 API 35） | 全链路用户体验 | 人肉点 + adb 断网 | 每里程碑 |
| 演练 | — | 模拟答辩（提问 + 断网演示） | 口头 | M3 |

三条原则：
1. 自动化不依赖真网——网络层一律手写 Fake（不引 mock 框架，答辩时每一行讲得清）；
2. 测试能不能过不靠运气——真网行为只进手工清单；
3. UI 不做自动化——课程规模性价比最高的取舍。

## 2. L1 单元测试用例

### DateParserTest（兼容性 + 绝不抛异常）

| 用例 | 输入 | 期望 |
|---|---|---|
| RFC-822 标准带时区 | Sat, 22 Nov 2026 10:30:00 +0800 | 正确毫秒 |
| RFC-822 GMT | …10:30:00 GMT | 正确毫秒 |
| 单数字日（脏格式） | Sat, 3 Nov 2026 … | 兼容解析 |
| ISO-8601 带时区 | 2026-11-22T10:30:00+08:00 | 正确毫秒 |
| ISO 无时区 | 2026-11-22T10:30:00 | 本机时区解释 |
| 纯日期 | 2026-11-22 | 当日 0 点 |
| 坏串 / null / 空 | "不是日期" | 返回 null 不抛（同步永不被一条坏数据打断） |

### HtmlTextTest
剥 script/style 整段丢弃；命名实体（&amp;）与数字实体（&#8212;）解码；超长截断加省略号；纯文本直通；全空返回 null。

### RssMapperTest
guid 优先 → link 兜底 → 两者皆无丢弃（不发明哈希）；pubDate 坏串 → null；空白标题 → null。

### OpmlParserTest / OpmlWriterTest（M3）
标准 outline 解析；导出→导入往返一致；非法输入报具体错误分类。

## 3. L2 仓储集成测试（Robolectric + 内存 Room）

| # | 场景 | 断言 |
|---|---|---|
| 1 | 同步幂等（全项目最重要） | 插一批 → 标已读 → 再插同批 → 行数不变、已读保留 |
| 2 | 唯一索引 | 同 (feedId, articleKey) 不同内容 → 只留第一行（IGNORE） |
| 3 | 外键 CASCADE | 删 feed → 其文章清零 |
| 4 | 列表排序 | 混入已读/无日期 → 未读优先、时间倒序、null 沉底 |
| 5 | addFeed 三分类失败（Fake：404 / 断网 / 坏 XML） | 均不入库、Result.failure 类别正确 |
| 6 | 304 跳过（Fake 返回 NotModified） | 不写文章、lastSyncAt 照常更新 |
| 7 | 错误隔离 | 多源中一个抛错 → 其他源照常入库；失败源 lastSyncError 有值、整体不中断 |
| 8 | 状态回写 | 刷新后 lastSyncAt 非空 |

场景 1 与 7 对应答辩最常被追问的两问："已读为什么刷新不丢""一个源挂了怎么办"。
