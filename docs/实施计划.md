**M1 关键技术决定（均已源码/实查核实）**：

- RSS-Parser 实例化 `RssParserBuilder().build()`，只用 `parse(xml)` 纯解析；6.0.10 源码确认 `parse` 是挂起函数、内部自带 `Dispatchers.Default`；
- `RssItem` 字段：guid / title / link / pubDate（原始字符串，需自写 DateParser）/ description / content / image；
- OkHttp **4.12.0**（Maven Central 最新稳定，5.x 尚在 alpha.16）；
- 依赖与构建基线 = todo-app 已在本机验证的配置原样平移（机器调优过的 gradle.properties、gradle-daemon-jvm.properties 的 JDK25 工具链条件、wrapper 9.4.1 本机缓存）；
- minSdk 26（直接用 java.time，免 desugaring）。
